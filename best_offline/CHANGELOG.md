# Changelog

- Update Highlight.js to 11.12.0, with 193 bundled languages.
- Update compatible RHEL7 dependencies: PyYAML 6.0.1 and watchdog 2.3.1.
- Update RHEL9 and Windows to Markdown 3.9 and PyMdown Extensions 10.21.3.
- Add reusable API and runbook templates, a workflow guide, and troubleshooting.
- Reject duplicate HTML anchor IDs during the site audit.
- Add an explicit, connected dependency-status command.

- Update the manifest version during theme-only refreshes and check wheel
  metadata against manifest versions and lock entries.

See DEPENDENCIES.md for retained pins and validation/RESULTS.md for verification.
